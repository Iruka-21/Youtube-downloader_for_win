# YouTube Batch Downloader Pro

CustomTkinter と yt-dlp を使用した、軽量・安全な YouTube 一括ダウンロードアプリです。

## 🌟 主な機能
- **自動FFmpegセットアップ**: 変換エンジンを自動で取得・構成。
- **一括ダウンロード**: 複数URLやプレイリストを連番付きで一括取得。
- **画質選択**: 最高画質 (自動) / 1080p / 720p / 480p / 音声のみ (MP3)。
- **W進捗バー & リアルタイムログ**: 処理状態や速度、ETAを可視化。
- **追加機能**: サムネイル埋め込み、字幕取得、ワンクリックエンジン最新化。
- **プライバシー保護**: ブラウザの個人データ・Cookieへのアクセスなし。
